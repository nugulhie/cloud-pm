# 솔닥 Cloud PM 디자인 개편

## 브랜드 기준

- [솔닥 공식 홈페이지](https://soldoc.co.kr/)의 로고에서 파랑 `#008DEF`, 주황 `#FC7E2F`를 확인했다. 로고 원본은 [공식 SVG](https://soldoc.co.kr/assets/business/shared/soldoc_logo.svg)다.
- 네이비 `#102B46`는 업무 메뉴와 본문을 구분하기 위해 추가한 화면 색상이다.
- 흰 글자를 사용하는 주요 버튼은 대비를 확보하도록 파랑을 `#006FBF`로 조정했다. 주황은 선택 표시와 주목할 항목에 사용한다.
- 공식 홈페이지에서 사용하는 Pretendard를 로컬 파일로 제공한다. 배포 라이선스는 `public/fonts/LICENSE.Pretendard.txt`에 보존했다.

## 화면 구성

- 짙은 왼쪽 메뉴에 공식 로고를 배치하고, 업무·문서·활동·관리로 탐색을 구분한다.
- 프로젝트 현황은 진행률·담당자·일정을 나란히 비교하는 행 목록으로 제공한다.
- 요약 수치는 별도 카드 대신 한 줄로 배치한다. 확인이 필요한 작업과 최근 태스크를 먼저 보여주고, 브리핑은 아래에 둔다.
- 태스크·PRD·GitHub 활동·모달·설정에 같은 버튼, 테두리, 글꼴 규칙을 적용한다. 완료·차단 상태와 코드 diff의 의미 색상은 유지한다.
- 태스크의 담당 계정·우선순위·스프린트·마감일 필터는 접어서 제공하며 적용된 조건 수를 표시한다. 모바일 검색 영역은 한 줄로 배치한다.

## 검증

로컬 격리 데모에서 390·768·1024·1440px 화면, 프로젝트 생성·삭제, PRD, 태스크 수정, 설정 모달, GitHub diff를 확인한다. 태스크 UX 테스트는 모바일 첫 태스크의 위치와 상세 필터의 펼치기·접기 및 조건 적용을 검사한다.

계정·권한·GitHub 동기화 API 계약과 데이터 모델은 변경하지 않는다. 실제 GitHub 계정 변경 대신 기존 로컬 HTTP 시뮬레이션으로 담당자·공유 보기·스프린트 흐름을 검증한다.
