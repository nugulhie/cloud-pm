# 개인 설정과 태스크의 GitHub 연결

왼쪽 아래 프로필을 누르면 설정 모달이 열립니다. 데스크톱은 왼쪽 메뉴, 모바일은 가로 탭으로 이동하며 오른쪽 내용 영역을 스크롤합니다. 방향키와 Home·End로 탭을 이동할 수 있습니다.

- **프로필**: 표시 이름을 수정하고 로그아웃합니다.
- **GitHub 연결**: 개인 GitHub 토큰을 저장·교체합니다. 조직의 공용 연결을 사용하면 개인 토큰은 필요하지 않습니다.
- **MCP·API**: 현재 워크스페이스용 개인 토큰 발급·폐기, Claude 연결 주소와 연결 점검을 제공합니다. 새 토큰은 현재 모달에서만 확인할 수 있고 재발급하면 이전 토큰이 만료됩니다.
- **워크스페이스**: 공간 전환·생성과 멤버·초대·공용 GitHub 연결을 관리합니다. 관리 동작은 기존 워크스페이스 역할을 따릅니다.
- **보안**: 비밀번호를 변경합니다.

탭을 옮겨도 작성 중인 입력과 방금 발급한 토큰은 유지됩니다. 모달을 닫으면 일회성 토큰 표시는 사라지고, 다른 워크스페이스로 전환할 때도 초기화합니다.

PRD에서 발행한 이슈는 해당 PRD가 전환된 태스크에 승인된 연결로 저장됩니다. 계층·목록·보드의 태스크에 **이슈 #번호 / PR #번호**가 표시되며, 태스크 상세의 **연결된 GitHub 항목**에서 제목·저장소·원본 링크·상태를 바로 확인할 수 있습니다. 연결 후보와 해제된 항목은 확정 연결로 표시하지 않습니다. 기존 항목의 연결·해제는 **GitHub 연결 관리**를 펼쳐 진행합니다.

GitHub 활동의 상세 창은 열 때 최신 수신 데이터를 조회하고, 열려 있는 동안 15초마다 제목·본문·담당자·라벨·상태·파일 변경을 갱신합니다. **최신 내용 새로고침**으로 즉시 확인할 수도 있습니다. Markdown 원문·미리보기 선택은 유지됩니다. GitHub 원문의 편집은 연결된 내부 태스크의 제목·설명을 자동 변경하지 않습니다.
